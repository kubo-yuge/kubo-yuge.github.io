# radian.cdyの説明

ご提示いただいたスクリプトは、**「円に巻き付いた糸をピンと張ったままほどいていく様子（円のインボリュート / 糸巻き線）」**、あるいは「円弧の長さを直線に引き延ばして比較する様子」を視覚的に説明するための動的な図（アプレット）を描画するものです。

高校数学の「弧度法（ラジアン）の定義：弧の長さ＝半径×中心角」や、媒介変数表示の単元でよく用いられる教材用の図式です。

コードの処理を読み解くと、図の構成と数学的な意味は以下のようになっています。

### 1. 描画される図の基本構成

* **半径3の円:** 原点O(0,0)を中心に、始点X(3,0)を通る円が描かれます。
* **展開された数直線（右側）:** 点X(3,0)から右に向かって水平線が伸びており、そこに $\frac{\pi}{2}$、$\pi$、$2\pi$ という目盛りが打たれています。これは円周の長さを直線として表したものです（半径が3なので、実際の座標は $3 + 3 \times \frac{\pi}{2}$ などの位置になります）。
* **2つのスライダー（A と C）:** * `C` は角度 `the`（全体の中心角）を制御します。
* `A` は角度 `tha`（糸が円から離れる接点の位置）を制御します。



### 2. 数学的なギミック（赤色と水色の線の関係）

スクリプトの後半にある条件分岐（`if`文）と、最後に配置されるテキスト `"水色の線と赤色の線は，同じ長さ"` がこの図の最大のポイントです。

スライダーを動かしたとき、次のような変化が起きます。

* **スライダーA（`tha`）が0以下のとき:**
点X(3,0)から上に向かってまっすぐな水色の垂線が描かれます。同時に、原点から角度 `the` までの円弧が赤色で描かれます。このとき「水色の直線の長さ」と「赤色の円弧の長さ」は同じです。
* **スライダーA（`tha`）をプラス方向に動かしたとき:**
「水色の直線」が円周に巻き付くように曲がり（ここが水色の弧になります）、点Pで円から離れて接線方向へまっすぐ伸びる線分PQ（水色の直線）になります。
このとき、**「円周上の赤色の弧（点Pから点Rまで）」の長さと、「接線方向に伸びた水色の直線（点Pから点Qまで）」の長さが常に等しくなる**ように計算されています。
* ※コード上の計算式 `3*(the-tha)` がまさにそれを示しています（半径 $\times$ 残りの中心角）。



### まとめ

このスクリプトが描く図は、「円周の一部（赤い弧）をペリッと剥がして、まっすぐな直線（水色の線）に伸ばしても長さは変わらないよ」ということを、スライダーを使ってアニメーションで直感的に見せるためのものです。
